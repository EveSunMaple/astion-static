# Astion Theme 规范

> 版本 v3 · 2026-10-08
> 设计方法：frontend-design skill（定方向 → 自审 → 实施 → 复盘）
> 约束：不再使用 daisyUI；仅 Tailwind 工具类 + 本规范定义的语义化样式

---

## 1. 设计命题

**对象**：Astion —— 以 Notion 为数据源的静态写作站；两类内容：说说（短动态）与博客（长文）。
**读者**：写作者与开发者，中英混排，长文阅读为主。
**首要任务**：让「记录」这件事没有摩擦，让列表像数据库一样可扫描，让正文像纸面一样安静。

**视觉概念：数据库视图 × 纸面（Database on Paper）**

- 列表是同一张数据库的视图：严格列对齐、等宽数字、每行同一基线，结构本身传递信息；
- 正文是纸面：一个测量宽度、一套间距节奏、一种强调色，除此之外没有装饰；
- 唯一记忆点：**列表行的选中带**——hover/当前行出现整行浅色底 + 左侧 2px Notion 蓝竖条（类似 Notion 的 block 选中），这是全站唯一“有表情”的动效；其余一律克制。

方向由既往 brief 锁定：Notion 风格（白底、暖灰、近黑文字、单一蓝色强调、极细边框）。本规范在锁定方向上做精确化，而非更换风格。

## 3. 字体与字号

**字体族**（不使用 webfont，保证首屏与中文一致性）：

```
--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
--font-mono: ui-monospace, "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

**字阶**（中文正文行高 ≥1.7；标题越大行高越紧、字距越负）：

| 角色 | 字号 | 字重 | 行高 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- |
| Display | 40px | 700 | 1.15 | -0.02em | 详情页标题 |
| Title | 30px | 700 | 1.2 | -0.015em | 列表页/About 标题 |
| H2 | 26px | 600 | 1.3 | -0.01em | 正文一级小标题 |
| H3 | 20px | 600 | 1.4 | 0 | 正文二级小标题 |
| Lead | 20px | 400 | 1.5 | 0 | 页头描述 |
| Body | 17px | 400 | 1.75 | 0 | 正文、列表摘要 |
| UI | 15px | 500 | 1.5 | 0 | 导航、按钮、行标题 |
| Caption | 14px | 400 | 1.55 | 0 | 次要说明、页脚 |
| Micro | 12.5px | 500 | 1.4 | +0.01em | 药丸、计数、表头 |

规则：

- 数字使用 `font-variant-numeric: tabular-nums`（日期、字数、计数）；**不使用等宽字体做标签**（仅代码块用 mono）。
- 行标题 500，hover 不变粗（避免抖动）；页面标题 700。
- 正文测量宽度 ≤ 68ch；中英混排在汉字与拉丁之间保留半角空格（内容侧约束）。
- 禁止：全大写标签、标题内单点强调（某个词变色/斜体）、装饰性 eyebrow 小字。

## 4. 间距与网格

**基线 4px，节奏 8px**。允许值：`2 4 8 12 16 24 32 40 48 64 80`。

### 4.1 应用外壳（三栏线性网格）

```
┌──────────┬─────────────────────────────────────────────────────────────┐
│          │ TopBar 48px · 面包屑左 · 操作右                              │
│ Sidebar  ├─────────────────────────────────────────────────────────────┤
│ 240px    │                                                             │
│ 固定      │   ┌── 阅读栏 680px ──┐  64px  ┌─ 大纲 192px ─┐              │
│ 全高      │   │  页头 48/24       │         │ sticky        │              │
│ 暖白底    │   │  列表 / 正文       │         │               │              │
│          │   └──────────────────┘         └───────────────┘              │
│          │   （外壳内容区最大 936px，居中；≥1280px 才显示大纲栏）           │
└──────────┴─────────────────────────────────────────────────────────────┘
```

| 参数 | 值 |
| --- | --- |
| 侧栏宽 | 240px（<1024px 收为抽屉） |
| 阅读栏 | 680px（所有页面一致：列表、详情、About） |
| 大纲栏 | 192px，仅 `≥1280px` 显示，与阅读栏间距 64px |
| 外壳左右留白 | 桌面 24px / 平板 20px / 手机 16px |
| TopBar 高 | 48px，底部 1px `--border` |
| 页头 | 上 48px / 下 24px（列表页与详情页一致） |
| 段落间距 | 0.75em；标题上距 1.8em/1.4em/1em（h2/h3/h4） |

### 4.2 列表（数据库视图）

列定义（左对齐，行内垂直居中）：

```
日期 88px │ 主栏 flex（标题 + 摘要 + 标签） │ 右栏 96px（封面缩略图 / 计数）
```

- 行高 ≥ 44px；padding `10px 12px`；行间距 0（靠 hover 底区分隔），表头下方 1px `--border-soft`。
- hover 底色从阅读栏左缘外扩 12px（负 margin），文字仍与列线对齐——底衬动、字不动。
- 选中带：`box-shadow: inset 2px 0 var(--accent)`，与 hover 同现。
- 首页列表与 /blog 列表使用同一套列定义；表头仅 /blog 显示。

### 4.3 对齐红线

- 所有左侧内容（标题、摘要、正文）共享同一条 0px 基线；缩进只允许来自列表符号与引用。
- 日期列右对齐数字（宽度固定 88px）；计数与阅读时长在元信息行内以 16px 间距分隔（不用 `·` 连接）。
- 图片：正文内圆角 8px、居中；列表缩略图 160×100、圆角 4px、object-fit cover。
- 卡片：**全站无装饰卡片**；只有弹窗、代码块、Callout 有底与描边。

## 5. 圆角、描边与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 4px | 按钮、输入框、列表缩略图、行 hover 底 |
| `--radius-md` | 8px | 正文图片、代码块、Callout、面板 |
| `--radius-lg` | 12px | 弹窗、抽屉 |
| `--radius-pill` | 9999px | 标签药丸、头像 |

描边一律 1px `--border`（“耳语边框”）；分隔线用 `--border-soft`。
阴影只用两层：`--shadow-raised`（弹窗/弹层，4 层 ≤0.05 透明度）与 `--shadow-focus`。

## 6. 组件规范

- **按钮**：高 32px，padding `0 12px`，圆角 4px，15px/500。
  - 主：蓝底白字，hover `--accent-hover`，active `scale(.98)`；
  - 次：`--surface-2` 底、`--fg` 字；
  - 幽灵：透明底，hover `--surface-2`；仅图标时 32×32。
  - 焦点：`0 0 0 2px var(--bg), 0 0 0 4px rgba(0,117,222,.45)` 双环。
- **药丸标签**：高 22px，padding `0 8px`，12.5px/500，`--surface`（可点击 hover `--surface-2`）；强调药丸用 `--accent-soft` + `--accent` 字（仅状态）。
- **侧栏项**：高 32px，padding `0 8px`，15px/500，`--muted`；hover `--surface-2`/`--fg`；当前项 `--fg` + `--surface-2` + 左侧 2px 蓝条。组间以 16px 分隔，不加小标题装饰。
- **输入框**（搜索）：高 32px，`--surface` 底无描边，focus 显示双环；占位符 `--meta`。
- **大纲项**：14px/400，`--meta`；当前项 `--fg` + `--surface-2` 底；缩进每级 12px。
- **分页**：高 32px 幽灵按钮组，当前页 `--surface-2`；上一页/下一页为纯文字按钮。
- **空状态**：图标 20px `--meta` + 一句可执行的提示（14px `--muted`），垂直 64px 内边距。
- **弹窗**：8px 圆角？→ 12px，`--bg`，1px `--border`，`--shadow-raised`；遮罩 `rgba(0,0,0,.3)`。
- **列表头**：12.5px/500 `--meta`，下 1px `--border-soft`，padding `0 12px 8px`。

## 7. Notion 内容块（正文内）

- 段落 17/1.75；行内 code `rgba(135,131,120,.15)` 底、`#eb5757` 字、3px 圆角。
- 引用：左侧 3px 当前色系竖线，缩进 14px，无底色。
- Callout：8px 圆角、`16px` 内边距、图标 18px，8 组底色（灰/棕/橙/黄/绿/蓝/紫/粉，暗色对应降明度版本）；正文与图标同一基线。
- Toggle：三角 12px `--meta`，summary 高 28px，hover `--surface-2`。
- 表格：1px `--border` 全网格，表头 `--surface` 底 500 字重，单元格 padding `7px 9px`。
- 待办：14px 方框，与文字 8px 间距，勾选后 `--meta` + 删除线。
- 代码块：`--surface` 底（亮）/ `#1f1f1f`（暗），圆角 8px，padding 16px，行高 1.6，仅此处使用 mono。
- 图片：圆角 8px；caption 13px `--meta` 居中，与图片间距 8px。

## 8. 动效

- 交互反馈 150ms、面板开合 200ms，缓动统一 `cubic-bezier(0.2, 0, 0, 1)`。
- 唯一的页面级动效：Swup 内容切换 220ms（opacity + 6px 上移），侧栏/TopBar 不动；不做逐区块入场动画、不做卡片 hover 位移。
- 允许的用户触发动效：菜单开合、主题切换图标 200ms、返回顶部平滑滚动、TOC 当前项底衬移动。
- `prefers-reduced-motion: reduce` 时全部关闭，仅保留状态切换。

## 9. 自审（对照“AI 生成感”清单）

| 常见默认 | 本规范的处理 |
| --- | --- |
| 奶油底 + 衬线大标题 + 陶土色 | 不使用；白底 + Inter + 单一蓝 |
| 近黑底 + 荧光强调 | 不使用 |
| 报纸风发丝线 + 零圆角 | 部分相似（细边框），但圆角 4/8/12 分级、无密集栏 |
| 统一圆角卡片 + 柔和阴影堆砌 | **全站无装饰卡片**；只有弹窗有阴影 |
| 全大写 eyebrow 标签 | 不使用；组标签为 12.5px 句子大小写 |
| 中点连接的元信息（A · B · C） | 不使用；改为 16px 间距的自然分词 |
| 数据标签用等宽字体 | 不使用；Inter + tabular-nums |
| 链接/按钮加 `→` | 不使用 |
| 每区块 fade-and-slide 入场 | 不做；只有一次页面切换动效 |
| 大数字 + 渐变英雄区 | 不使用；首页直接进入列表（内容即英雄） |

这就是本规范与原 daisyUI 实现最大的区别：**减少组件、统一节奏、把结构留给数据本身**。
